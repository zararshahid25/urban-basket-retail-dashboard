# Data folders

- `raw/` is generated by `python -m src.generate_data`.
- `processed/` contains PostgreSQL load-ready tables created by `python -m src.prepare_data`.
- `sample/sales_sample.csv` is a committed 300-row joined extract for quick review.

The full generated CSVs are excluded from Git because they are reproducible from source code. All customers, orders, products, and monetary values are synthetic.
